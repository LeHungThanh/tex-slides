# RITS consultation deck

The compiled 77-slide PDF and the supplied XeLaTeX/TikZ source for Session 3, Part E.

To compile from this directory:

```sh
xelatex -halt-on-error rits-consultation-deck.tex
xelatex -halt-on-error rits-consultation-deck.tex
```

The bundled `fonts/` and `figures/` directories must remain beside the TeX source.
